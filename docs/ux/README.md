# UX プロトタイプ

このディレクトリには、体験設計の一次資料となる**動くプロトタイプ**を置く。実装コードではなく、
「どんな体験を作るか」を関係者が同じ画面で見て議論するための参照物。

## knowledge-birth-prototype.html

「暗黙知が**形式知として生まれる瞬間**」を見せる 5 画面プロトタイプ。ブラウザで開くと各画面が自動再生される
（ネット接続時は Google Fonts を読むが、フォントが無くても内容は読める）。

| # | 画面 | 何を見せるか |
|---|---|---|
| 01 | 誰に聞くか（ROUTE） | 宛先決定＋質問文の整形＋候補の根拠開示 |
| 02 | 解決の検知（DETECT） | ボタン前提にせず Slack スレッドから捕捉（3段構え） |
| 03 | 抽出と修正（EXTRACT） | 会話ログ→知識単位の生成過程を線で見せる＋フィールド単位編集 |
| 04 | 突き合わせ（RECONCILE） | 🆕新規／🔄更新／⚠️矛盾を確定前に提示 |
| 05 | 確定と還元（COMMIT） | 質問者／回答者に別々の価値を返す（スコア非公開・opt-out公開） |

視覚上の約束: **会話＝ゴシック体／記録＝明朝体**。非構造の会話が構造化された記録に変換される過程を、書体の
切り替えで表している。

出典: 2026-08 の UI/UX 壁打ち。エピック **#474**、子Issue **#475–#480**。UI 土台の判断は **ADR-0011**。
