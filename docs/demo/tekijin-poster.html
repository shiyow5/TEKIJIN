社内に散らばる暗黙知を、AIが形式知として蓄え・巡らせる ── 社内エキスパートネットワーク。

発表者　Aチーム 所属　大塚商会 サマーインターン 2026 領域　RAG・専門家推薦・暗黙知の形式知化

TEKIJIN（適任）は、社内の相談に対して「AIが即答する／最適な人へ取り次ぐ／社内文書を示す」を自動で出し分け、解決の過程で生まれた知識を次の回答に還元するプラットフォームです。

背景・目的

社内の知見やノウハウは個人に属人化し、組織として再利用できていない。

  • 「この件は誰に聞けばよいか」が分からず、相談先の探索に時間がかかる。
  • 定型FAQや全文検索では答えられない、判断を要する相談が多い。
  • 解決の過程で生まれた知識が記録・共有されず、同じ質問が繰り返される。

目的：人・文書・蓄積知識を横断し、質問ごとに最適な形で応答しながら、暗黙知を組織の資産として形式知化する。

3つのシステム

SYSTEM 1

自己回答

蓄積済みの知識・過去回答から根拠付きで即答。構造化知識はLLM非依存の決定的合成で幻覚を抑える。

SYSTEM 2

適任者へ取次ぎ

質問に最も適した社員を特定し、Slackの専用チャンネルで依頼者と接続する。

SYSTEM 3

知識の蓄積

解決した会話から知識を抽出。承認ゲートを経て形式知化し、System 1 で再利用する。
